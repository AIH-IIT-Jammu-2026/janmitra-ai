# Technical Documentation - JanMitra AI

## Tech Stack
- **Frontend**: React (Vite), Framer Motion, React Markdown, React Router DOM
- **Backend**: FastAPI, Python 3.10+, Uvicorn, Pydantic
- **AI Stack**: Google Gemini API, LangChain / LangGraph, Custom Agent Router
- **Vector DB / Storage**: Supabase / FAISS (RAG pipeline ready)

## Directory Structure
- `src/` (Frontend React Application)
- `backend/` (FastAPI Server & AI Agent Pipeline)
- `docs/` (System Documentation)
